# Cool Apps plugin support

Bug reports and feature requests for the [Cool Apps](https://coolapps.fyi) Minecraft server plugins:

| Plugin | Docs | Download |
|---|---|---|
| **AFK Warden**: anti-AFK for Paper and Spigot | [coolapps.fyi/plugins/afkwarden](https://coolapps.fyi/plugins/afkwarden/) | [Modrinth](https://modrinth.com/plugin/afkwarden) |
| **ChatShield**: chat moderation with a self-hosted web panel | [coolapps.fyi/plugins/chatshield](https://coolapps.fyi/plugins/chatshield/) | [Modrinth](https://modrinth.com/plugin/chatshield) |

This repository only holds issues. The plugins' source code is not public.

## Report a problem

1. Check the plugin's docs and FAQ first; many questions are answered there.
2. [Open an issue](https://github.com/coolapps-fyi/support/issues/new/choose) and pick **Bug report** or **Feature request**.
3. Include the plugin version, your server software and Minecraft version, your Java version and the console lines
   around the problem. English or Spanish, both are fine.

**Never post license keys, passwords, tokens or your server's IP address in an issue.** Issues are public.

## Not for issues

- **Purchases, licenses and refunds:** write to [support@coolapps.fyi](mailto:support@coolapps.fyi) with your order
  number. See [coolapps.fyi/support](https://coolapps.fyi/support/).
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).
